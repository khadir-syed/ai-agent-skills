# Content draft + readiness format

## Gap report summary (from step 1)

- **Investigation status:** clear enough to draft from / gaps identified / too ambiguous
- Key gaps, each labelled Stated / Reported / Inferred / Unknown

## Content draft (drafted in step 2 — written only after approval)

- **Source used:** which brief, notes, or gap-investigation report the draft is based on
- **Draft:** the requested piece or section, written in full, matching the stated tone, audience, and format
- **Open questions carried over:** anything left unresolved from step 1

## Readiness checklist (step 3)

| Check | Status | Evidence |
|---|---|---|
| Proofread for errors and placeholder text | Pass / Fail | |
| Links resolve to a real destination | Pass / Fail / Could not determine | |
| SEO basics present | Pass / Fail / N/A | |
| Images have alt text | Pass / Fail / N/A | |
| Facts and claims are sourced | Pass / Fail / Could not determine | |
| Tone matches brand/style guide | Pass / Could not determine | |

## Overall summary

State the picture in one or two sentences, phrased as input to a publish
decision, not the decision itself. Call out any "Could not determine" rows
and any open question carried over from the gap report explicitly.
