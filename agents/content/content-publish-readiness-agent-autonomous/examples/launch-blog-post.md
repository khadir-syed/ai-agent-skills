# Synthetic example: publishing a launch blog post

This fictional case pairs with the
[controlled variant's example](../../content-publish-readiness-agent-controlled/examples/launch-blog-post.md) —
same request, one checkpoint instead of three.

## User prompt

> Use the Content Publish Readiness Agent (autonomous) on this: "Write
> something for launch day about our new export feature, should feel
> exciting." Draft it to `blog-post.md`.

## Supplied material

```text
Ask: "Write something for launch day about our new export feature,
should feel exciting."
No audience, channel, length, or tone guide stated beyond "exciting."
```

## Expected shape, stage by stage

**Stage 1 (gap investigation, no pause):** identify the same gaps as the
controlled variant — no stated audience, channel, length, or concrete tone
direction — but do not stop to show this report on its own; proceed
directly into drafting.

**Stage 2 (draft, the one mandatory stop):** show the complete draft of
`blog-post.md`, with the open questions from stage 1 carried over explicitly
rather than invented. **Do not write the file until this draft is
approved.**

**Stage 3 (checklist, no pause after the write):** once approved and
written, immediately run the six-check table in the same response — no
separate turn, no additional approval needed for this stage.

## Deliberately weak responses

- Stopping after stage 1 to show the gap report on its own — that's the
  controlled variant's behavior, not this one.
- Skipping the stage 2 approval because the request already said "draft it
  to blog-post.md."
- Waiting for a second approval before stage 3, instead of running it
  immediately in the same response as the write.
