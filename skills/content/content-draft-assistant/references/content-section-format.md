# Content section draft format

Use whichever of these the brief actually calls for — don't force every field.

## Source used

State which brief, notes, or gap-investigation report the draft is based on.

## Draft

The requested piece or section, written in full, matching the stated tone, audience, and format.

## Open questions (not filled in)

Anything the source material didn't support — a missing statistic, an unconfirmed claim, an undecided call to action — listed explicitly rather than guessed at.

## Approval requested

State plainly what file (and location within it) this will be written to, and that no write has happened yet.
