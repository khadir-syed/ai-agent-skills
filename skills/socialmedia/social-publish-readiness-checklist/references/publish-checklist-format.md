# Social publish readiness checklist report format

## Source

State what was checked (a file, doc, or pasted text), which platform it targets, and whether a posting calendar was supplied.

## Checklist results

| Check | Status | Evidence |
|---|---|---|
| Within the platform's character limit | Pass / Fail / Could not determine | |
| Hashtags are formatted and relevant | Pass / Fail / Could not determine / N/A | |
| Media meets platform specs | Pass / Fail / Could not determine / N/A | |
| Alt text or captions present on media | Pass / Fail / Could not determine / N/A | |
| Links are tracked and resolve to a real destination | Pass / Fail / Could not determine / N/A | |
| No scheduling conflict | Pass / Fail / Could not determine | |

## Summary

State the overall picture in one or two sentences. Do not phrase it as a publish decision — it's input to whoever makes that call. Call out any "Could not determine" rows explicitly rather than letting them read as passes.
