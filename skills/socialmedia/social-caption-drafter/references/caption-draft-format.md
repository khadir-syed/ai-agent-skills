# Social caption draft format

## Source used

State which brief, notes, or gap-investigation report the draft is based on, and which single platform this draft targets.

## Draft

The caption, written in full, matching the stated tone, audience, and platform.

## Assumptions made explicit

Any platform convention assumed but not confirmed (e.g. an approximate character limit, typical hashtag count) — flagged as an assumption, not presented as fact.

## Open questions (not filled in)

Anything the source material didn't support — a missing hashtag strategy, an unconfirmed link, an undecided call to action — listed explicitly rather than guessed at.

## Approval requested

State plainly what file this will be written to, and that no write has happened yet.
